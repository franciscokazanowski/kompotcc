# Contribuir com a Kompô

Abra uma issue descrevendo a dificuldade, o dispositivo e uma forma de reproduzir o problema. Não publique dados pessoais nem capturas de contas de terceiros.

Para contribuir com código, crie uma branch, faça a alteração e execute `pnpm typecheck`, `pnpm test:db` e `pnpm build`. Explique no pull request o comportamento alterado e as verificações realizadas.

Mudanças de conteúdo precisam indicar fonte confiável e distinguir fermentação dos restos de alimentos da etapa posterior de decomposição. Novas trilhas, como minhocários, exigem fontes e cuidados próprios. Preserve os identificadores de lições e os índices das respostas ao revisar textos; alterações das regras persistidas exigem migração correspondente.

A aceitação de contribuições depende da licença definida pelo autor no repositório.
